# Roadmap · MD.studio

## Disponible

| Área | Estado |
| :--- | :--- |
| Escritura | Editor Markdown como pantalla inicial y creación de notas en blanco. |
| Lectura | Vista previa desplazable y vista dividida opcional en escritorio. |
| Documentos | Biblioteca, carpetas, búsqueda, plantillas e historial local. |
| Respaldo | Descarga y restauración del espacio en ZIP. |
| Exportación | Markdown, HTML, impresión como PDF y ZIP de recursos. En Android, la opción de compartir envía una copia del Markdown a aplicaciones compatibles. |
| Publicación | Cloudflare Pages sirve el editor en [md.rck1996.dev](https://md.rck1996.dev/). |

## Próximas comprobaciones

1. Repetir el flujo completo de **Enviar a NexusOS** con el editor publicado y un Android que tenga el receptor instalado.
2. Comprobar teclado, contraste y navegación táctil en dispositivos Android y iOS de tamaños distintos.
3. Verificar un ciclo de respaldo y restauración con una biblioteca grande que incluya imágenes y versiones.
4. Probar el arranque sin conexión después de instalar la app en navegadores compatibles.
5. Renovar la galería de PC y móvil cuando cambien las rutas principales.
